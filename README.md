# A To Z Mart

A modern responsive online shopping website built with:

- HTML
- CSS
- JavaScript
- Supabase
- GitHub Pages

## Features

- A To Z Mart branding
- Product collection
- 4-page product pagination
- Previous / Next buttons
- Search products
- Category filtering
- Favorites
- Shopping cart
- Checkout form
- Customer name
- Customer phone
- Delivery address
- Supabase order storage
- Order items storage
- Admin login
- Admin order dashboard
- Responsive mobile design
- Contact section
- About section
