# A TO Z MART

A modern GitHub Pages shopping website.

## Features

- A TO Z MART branding
- Modern pink, purple and blue design
- White typing/search boxes
- Black text while typing
- Product search
- Category filter
- Clothes
- Fashion
- Jewellery
- Accessories
- Beauty
- Perfumes
- Luxury Abaya
- Favorites
- Shopping cart
- Separate Contact tab
- About tab
- Next/Previous pagination
- Four products per page
- Four pages of products
- Responsive mobile design
- No Streamlit
- No Python
- GitHub Pages compatible
